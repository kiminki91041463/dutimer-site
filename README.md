# Dutimer support site

Static support and privacy pages, in English and Korean. No build step, JavaScript, analytics, or third-party fonts.

- `index.html`: English support
- `privacy.html`: English privacy policy
- `ko.html`: Korean support
- `privacy-ko.html`: Korean privacy policy

Support: dutimer.app@outlook.com

This repository contains only the public website, not the application source code.
